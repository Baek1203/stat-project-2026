# 통계 프로젝트 웹 앱

중1 통계 프로젝트(탐구 문제 설정 → 자료 수집 → 자료 분석 → 결과 해석)를 모둠별로 진행하는 웹 앱입니다.

- 학생 화면: `index.html` (모둠 입장 코드 + 번호 + 비밀번호 4자리)
- 교사 화면: `teacher.html` (구글 로그인)
- 보안 규칙: `firestore.rules` (Firebase 콘솔에 붙여 넣고, 교사 이메일은 콘솔에서만 바꿈)
- 설정: `js/firebase-config.js` (Firebase 웹 앱 설정값 6개)

설치 방법은 함께 드린 「통계프로젝트_웹앱_설치안내」를 보세요. 자료(원자료 58장)는 이 저장소에 없고, 교사 화면에서 JSON 파일을 불러와 Firestore에 저장합니다.

| 파일 | 하는 일 |
| --- | --- |
| js/student.js | 학생 화면(단계별 활동, 자동 저장, 자료 도서관, 그래프 올리기, 보고서) |
| js/teacher.js | 교사 화면(자료 불러오기, 반·모둠, 차시 시작, 현황판, 주제 추첨, 기록·CSV) |
| js/common.js | 단계, 차시 안, 역할, 과업, 노트 문항 등 공통 설정 |
| js/util.js | 화면 도우미, 자동 저장, 그림 줄이기, CSV |
| js/fb.js | Firebase 연결(SDK 12.19.0) |
| css/style.css | 화면 모양 |
